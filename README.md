## 详细步骤
### 一、填写配置文件

在`.\config`目录下找到四个配置文件

- `API配置.toml` 配置Agent的API接口信息
- `常规配置.toml` 配置Agent的常规功能
- `记忆配置.toml` 配置Agent的记忆时间、最大token数等
- `指令配置.toml` 配置程序指令

参考注释和[toml填写规范](#toml填写规范)自行填写配置文件。

#### 必填项
API配置文件中，`api_key`、`base_url`、`model`为必填项，`extra_body`有参考值但不同服务商可能不同，报错请自行参考服务商的API文档进行调整，其他项可根据需要填写。

#### API配置说明
- 在各大模型平台申请API Key后，填写到`api_key`中即可。

- 安全起见，请将`api_key`填写到`.env`文件中，并将`[OpenAI.env]`下的`env`参数设置为`true`。此时`api_key`配置项将被忽略。

- `.env`文件的填写格式为`API_KEY_NAME=你的API_KEY`，其中`API_KEY_NAME`是API Key的名称，可自定义，但尽量全部使用大写字母和下划线，避免使用小写字母和其他符号。`你的API_KEY`为你申请的API Key，粘贴时请注意不要有多余的空格或换行，也不用将小写转换为大写。随后在`API配置.toml`中将`api_key_name`设置为你在`.env`中填写的`API_KEY_NAME`即可。

- 不要在`.env`文件中添加其他内容。

- `model`为模型名称，填写时请参考各大模型平台的模型名称。如果可以，尽量选择多模态模型，以便图片上传功能正常使用。

- `[OnlineSearch]`下的配置项与上述配置类似。搜索目前仅支持百度千帆搜索。申请流程请参考[搜索API申请流程](#搜索API申请流程)。

#### 常规配置说明
- 请确保模型为多模态模型，才可将`[Image]`下的`upload`设置为`true`。

- 请确保模型所属服务商支持OpenAI SDK的Files API，才可将`[Image]`下的`Files_API`设置为`true`。

#### 记忆配置说明
- 参考注释和个人需求自行填写。

#### 指令配置说明
- 在输入时使用`/配置的指令`进行操作。

- 注意：配置文件中指令不需要加`/`，否则在输入指令时会需要加两个`/`。

- 例如，将撤回指令配置为`rv`，则在输入时需输入`/rv`。

- 指令不可重复。若输入错误，将以普通消息发送。

### 二、编写提示词(Prompt)
根目录下的`system.md`文件为系统提示词，按照需求自行编写。

#### 相关说明
- 系统提示词为Agent的指导性文本，建议在编写时尽量详细。

- 格式没有严格要求，但建议使用Markdown格式，方便阅读。Markdown的语法可参考[Markdown语法说明](#Markdown语法说明)。

- 文本应清晰明了，避免Agent混淆角色或产生不必要的误解。

- 初始的`system.md`文件为模板，供参考。

### 三、运行程序
根目录下`Agent.exe`为程序入口，双击运行即可。

#### 说明
- `Agent.exe`的名称可自行修改。但应确保后缀为`.exe`，否则无法运行。

- 根目录的名称同样可自行修改。

- 除此之外，请勿进行修改其他文件或文件夹的名称、移动文件等操作，否则程序将会新建新的目录或文件，导致之前的配置文件和提示词无法使用。

## 功能说明
### 记忆
Agent的记忆功能分为短期记忆、指定记忆和长期记忆三种。

- **短期记忆**：完整保留Agent的所有对话内容。在达到`记忆配置.toml`中的最大天数和最大token数后，将会进入长期记忆。

- **指定记忆**：在对话中要求Agent记住某些内容时，Agent会将这些内容单独保存为指定记忆。指定记忆不会进入长期记忆，但将永久保留，除非手动删除。Agent无法主动删除指定记忆，如果有需要，参考[指令](#指令)。

- **长期记忆**：在达到`记忆配置.toml`中的最大天数和最大token数后，Agent会将短期记忆中的内容转化为长期记忆。Agent将根据语义和时间在长期记忆库中进行检索，并将检索到的内容作为上下文提供给Agent，以便更好地理解当前对话内容。

- 长期记忆将保留**1~2年**，具体时间取决于记忆保存时间。例如，进入新的年份后，将会自动删除年份差距超过2年的长期记忆。长期记忆的删除将会在有短期记忆将要转换为长期记忆时检查。

### 时间

- **获取当前时间**：Agent的时间为系统时间，包含日期和时间以及星期，Agent将根据系统时间进行判断和计算。

- **感知**：Agent可以获取上次对话与当前时间的差值，并根据差值判断输出的内容。

### 指令

- **撤回**：语法为`/撤回指令`，例如`/rv`。撤回指令将会撤回上一次的对话内容，虽然用户侧仍然可以看到，但Agent将不会记住撤回的内容。
    
    - 可选参数：

        > 注意，若在指令后加上空格，则会被识别为要携带参数，此时不带参数的指令将会失效。下同。

        - `n`：撤回最近的n轮对话内容，n为正整数。例如`/rv 3`将会撤回最近的3轮对话内容。

- **退出**：语法为`/退出指令`，例如`/q`。退出指令将会退出程序。可以采用快捷键`Ctrl+C`退出程序，或是直接关闭程序窗口，但不建议，可能会导致程序无法正常保存数据。

- **重载配置文件**：若在程序运行过程中修改了配置文件，可使用`/重载配置文件指令`，例如`/rc`来重新加载配置文件。

- **列出所有要求Agent记住的记忆**：语法为`/列出记忆指令`，例如`/lm`。列出记忆指令将会列出所有要求Agent记住的记忆内容以及对应id。

- **删除指定记忆**：语法为`/删除记忆指令 id`，例如`/dm 1`。删除指定记忆指令将会删除指定id的记忆内容。必须携带参数id，且id必须为正整数。若输入的id不存在，将会提示错误。

- **上传图片**：语法为`/上传图片指令`，例如`/i`。上传图片指令将会调出选择图片的窗口。可以使用`Ctrl`键或`Shift`键选择多张图片，也可以多次使用上传图片指令上传多张图片。上传的图片将会被Agent记在短期记忆中。

- **删除选择的图片**：语法为`/删除图片指令`，例如`/di`。将会取消上传所有选择的图片。

    - 可选参数：

        - `n`：删除选择的图片中第n张图片，n为正整数。例如`/di 3`将会删除选择的图片中第3张图片。

- ⚠️ **重置Agent** ⚠️： 语法为`/重置Agent指令`，例如`/reset`。重置Agent指令将会清空所有的短期记忆、长期记忆和指定记忆，需要二次确认。原则上指令不应少于3个字符。请谨慎使用。

### 工具调用
Agent可以调用工具来辅助完成任务。Agent会根据情况调用工具，如果觉得某个工具的调用需要确认，或是不希望确认，可以在`常规配置.toml`的`[Confirm]`下自行配置各个工具是否需要确认。操作不可以撤回，但仅删除操作会到不可挽回的地步。

- **文件操作**：Agent可以调用工具来进行文件的访问、创建、删除、读取、写入、移动、复制、重命名、查询操作。普通查看操作默认不需要确认，删除操作默认需要确认，且二者无法修改。

- **联网搜索**：若配置了联网搜索功能，Agent可以调用工具来进行联网搜索，获取网页的标题、链接和摘要信息。联网搜索默认不需要确认，且无确认此功能的配置项。

## 其他帮助
### TOML填写规范
- TOML文件的注释以`#`开头，注释内容不会被程序读取。

- TOML文件的键值对格式为`key = value`，键和值之间可以有空格，但不能有其他字符。键可以包含字母、数字、下划线和点号，但不能以数字开头。键的大小写敏感，建议使用小写字母和下划线。即使是字符串类型的键，也不需要用引号括起来。

- TOML文件的值可以是字符串、整数、浮点数、布尔值、数组或表格。字符串需要用双引号括起来，其余均不需要引号。布尔值为`true`或`false`，数组用方括号括起来，表格用方括号括起来，下属表格用点号分隔，例如`[a.b]`表示表格a下的子表格b。

### Markdown语法说明
Markdown是一种轻量级的标记语言，使用纯文本格式编写文档，然后转换为HTML格式。Markdown的语法简单易学，适合编写说明文档、博客文章、技术文档等，即使无关乎此程序，也建议学习。

- 基础语法:
    - 标题：使用`#`表示标题，`#`的数量表示标题的级别。例如：
        ```
        # 一级标题
        ## 二级标题
        ### 三级标题
        ```

    - 列表：使用`-`或`*`（后者不推荐）表示无序列表，使用数字加点表示有序列表。例如：
        ```
        - 无序列表项1
        - 无序列表项2
        1. 有序列表项1
        2. 有序列表项2
        ```

    - 链接：使用`[链接文本](链接地址)`表示超链接。例如：
        ```
        [百度](https://www.baidu.com)
        ```

    - 图片：使用`![图片描述](图片地址)`表示图片。例如：
        ```
        ![示例图片](https://www.example.com/image.jpg)
        ```

    - 粗体和斜体：使用`**`表示粗体，使用`*`表示斜体。例如：
        ```
        **粗体文本**
        *斜体文本*
        ***粗体斜体文本***
        ```

    - 引用：使用`>`表示引用。例如：
        ```
        > 这是一个引用文本
        ```
    
    - 分割线：使用`---`表示分割线。例如：
        ```
        ---
        ```
    
    - 注释：使用`<!-- 注释内容 -->`表示注释。例如：
        ```
        <!-- 这是一个注释 -->
        ```
    
    - 代码块：使用三个反引号（Esc下方的键）表示代码块，反引号后可指定语言类型。例如：
        ```
            ```python
            def hello():
                print("Hello, World!")
            ```
        ```

    - 表格：使用`|`表示表格的列，使用`-`表示表头和表体的分隔线。例如：
        ```
        | 表头1 | 表头2 |
        |-------|-------|
        | 内容1 | 内容2 |
        | 内容3 | 内容4 |
        ```

        使用`:`表示对齐方式，`:`在左侧表示左对齐，`:`在右侧表示右对齐，`:`在两侧表示居中。例如：
        ```
        | 左对齐 | 居中对齐 | 右对齐 |
        |:-------|:--------:|--------:|
        | 内容1  |   内容2  |   内容3 |
        ```

### docx（word文档）编辑相关

- Agent可以采用docx和md互相转换的方式来阅读和编辑word文档。

- md格式相对来说有局限性，无法完全保留word文档的格式和样式，例如字体、颜色、段落间距等。

- 但可通过设置`.\docx_example`目录下的`模板文件.docx`来控制md转换为docx时的格式和样式。模板文件中可以设置字体、字号、颜色、段落间距等。

## 常见问题
- Q：Agent.exe运行后崩溃，控制台闪退，无法看到报错信息。

    A：在文件资源管理器（文件管理）中，位于exe文件所在目录，在上方的地址栏输入`cmd`并回车，即可在当前目录打开命令提示符窗口。然后在命令提示符窗口中输入`Agent.exe`并回车，即可运行程序。若程序崩溃，报错信息将会显示在命令提示符窗口中。若无法解决，请上报问题。

- Q：Agent.exe运行后，显示`openai.error.……`。

    A：请检查`API配置.toml`中的`api_key`、`base_url`、`model`等是否填写正确，若不确定，请参考各大模型平台的API文档。

- Q：我忘记了历史对话内容，要怎么查看？

    A：在`.\memory`目录下，找到对应的历史对话文件`history.json`，使用文本编辑器打开即可查看。

- Q：我按`Alt+Enter`后没有正常输出，反而是控制台全屏了。

    A：右键点击控制台窗口的标题栏，选择设置，在快捷键中删除或修改`Alt+Enter`的快捷键。需要手动保存，并且请通过关闭上方的标签页来退出设置界面，而非点击右上角的关闭按钮，否则整个控制台窗口将会关闭，程序也会关闭。

其余报错均有提示信息，请根据提示信息自行排查问题。若无法解决，请上报问题。
